## Evidence handling and limits

Private lab credentials, browser passwords/tokens, Manager secret keys, registry databases, CA files, and Playwright traces are excluded from this export. Text and JSON files were checked against available lab/private secret bytes and credential-header, password-field, and private-key markers; no matches were found. The screenshots were inspected for visible credentials.

The core live worker fixture uses `t.TempDir`, so its registry and sidecar journal files are removed when the test exits. Its retained JSON capture contains native run, execution, log, and lifecycle observations. The browser harness's private Manager registry/journals and disposable lab databases remain outside this repository for local inspection; they are not included here. Cleanup of private retained resources is separate from this export.

The original `pg_sleep` reproduction and its later state are reported separately. The eventual disappearance and rollback do not convert the original cancellation failure into a PASS. No deployment, external registry modification, push, or merge is represented by these artifacts.

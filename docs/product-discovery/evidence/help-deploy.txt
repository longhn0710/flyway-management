Description:
    Deploys an individual script to an environment
    Can be used in conjunction with scripts generated by `flyway prepare`

Configuration parameters: (Format: -key=value)
    scriptFilename  A deployment script to run against an environment. Can be a script generated by `flyway prepare`. If not specified, will fall back to `prepare.scriptFilename`. If this is also absent, the location will default to deployments/D__deployment.sql
    saveSnapshot    Generate a snapshot on deployment success and embed it in the flyway snapshot history table. This can be used for drift checks.

Example:
    flyway deploy -deploy.scriptFilename=D__deploymentScript.sql -environment=production

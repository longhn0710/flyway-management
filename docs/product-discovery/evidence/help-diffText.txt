Description:
    Shows the object differences for changes computed by flyway diff

Configuration parameters: (Format: -key=value)
    diffText.changes           A comma seperated list of change ids. If unspecified, all changes will be used.
                               May specify - to read changes from stdin
    diffText.artifactFilename  The location of the diff artifact to apply to the target.
                               Defaults: diff.artifactFilename, %temp%/flyway.artifact.diff



Description:
    Prints out the object level differences from the differences generated by the diff command

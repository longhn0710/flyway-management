Description:
    Generates a migration script based on the changes from flyway diff
    The version, description and location of the migration script can be specified or auto-generated by flyway
    A corresponding undo script can also optionally be generated

Configuration parameters: (Format: -key=value)
    generate.changes            A comma separated list of change ids. If unspecified, all changes will be used.
                                May specify - to read changes from stdin
    generate.types              Comma separated list of types of script to generate.
                                Valid values: versioned|undo|baseline Default: versioned
    generate.version            The version part of the migration name.
                                If unspecified this will be calculated to either the next migration version if a versioned migration is specified, or the current version otherwise
    generate.description        The description part of the migration name
    generate.baselineFilename   The filename (or full path) to use for the generated baseline migration. Mutually exclusive with description & version
    generate.versionedFilename  The filename (or full path) to use for the generated versioned migration. Mutually exclusive with description & version
    generate.undoFilename       The filename (or full path) to use for the generated undo migration. Mutually exclusive with description & version
    generate.location           The location to generate the migration to
    generate.artifactFilename   The location of the diff artifact to apply to the target.
                                Defaults: diff.artifactFilename, %temp%/flyway.artifact.diff
    generate.force              If the migration script already exists, overwrite it. Default: false
    generate.timestamp          Add a timestamp to the calculated version if one is not already present.
                                Valid values: always|auto|never Default: auto
    generate.target             Set the direction of script generation by stating the target to use. Must equal one of source or target from flyway diff.
                                Defaults: diff.target if specified, otherwise the target of the artifact.
    generate.usePlaceholders    If true, placeholders will be automatically inserted into the generated migration script.
                                Default: false

Example:
    flyway generate -generate.target=migrations -generate.version=005 -generate.description='Add Table' -generate.location=/var/migrations
